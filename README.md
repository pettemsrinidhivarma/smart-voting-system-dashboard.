# Smart Voting System — Cats vs. Dogs Dashboard

A standalone, zero-dependency HTML/CSS/JS version of the **Smart Voting System (Cats vs. Dogs)** IoT voting dashboard that you can share with anyone or host anywhere.

## Included Files
- `index.html` — Dashboard layout, KPI cards, vote progress bars, donut chart, device health checks, recent activity table, and system architecture flow.
- `styles.css` — Responsive dashboard styling.
- `script.js` — Interactive voting buttons, live vote simulator (1x / 2x / 5x speeds), and one-click CSV export.

## How to Run & Share
1. **Run Locally:** Unzip the folder and double-click `index.html` to open it in any web browser (works completely offline).
2. **Share with Others:** Send this `.zip` file directly via WhatsApp, Telegram, email, or Google Drive—recipients simply unzip and open `index.html`.
3. **Host Free Online:** Drag and drop the unzipped folder into [Netlify Drop](https://app.netlify.com/drop), GitHub Pages, or Vercel to get a public link.
